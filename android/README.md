# Android Module (Ember Mobile)

This directory contains the Android application module and Rust FFI bridge (`ember-android-ffi`) for Ember.

## Architecture

- **`ember-ffi/`**: Rust crate compiling a libsodium-compatible UniFFI `cdylib` (`libember_android_ffi.so`). It bridges `ember-core` into idiomatic Kotlin without duplicating cryptographic algorithms or compromising key zeroization.
- **`app/`**: Android application module (API 26 floor, Target/Compile SDK 35/37) with Jetpack Compose UI.
- **`app/src/main/jniLibs/`**: Pre-built Android native shared libraries for `arm64-v8a`, `armeabi-v7a`, and `x86_64` (< 1 MB per ABI).
- **`app/build/generated/uniffi/kotlin/`**: Kotlin bindings generated by UniFFI 0.32.2 in package `com.ember.mobile.core`.

## Zero Google Services Constraint

Per the Ember privacy and architecture rules, the Android app contains **zero** Google Play Services, Firebase, FCM, ML Kit, or Nearby Connections dependencies.

This is strictly enforced by:
```powershell
powershell -ExecutionPolicy Bypass -File android/scripts/check_dependencies.ps1
```
and in CI via `android/scripts/check_dependencies.sh` and the Gradle task `:app:checkForbiddenDependencies`.

## Building Native Libraries

To build the native shared libraries for all supported Android ABIs and regenerate the Kotlin bindings:

```powershell
powershell -ExecutionPolicy Bypass -File android/build-native.ps1
```

Prerequisites:
- Android NDK 28+ (in `ANDROID_HOME` / `ANDROID_NDK_ROOT`)
- Rust toolchain with targets `aarch64-linux-android`, `armv7-linux-androideabi`, and `x86_64-linux-android`

## Running Tests

Host FFI unit tests:
```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_cargo.ps1 test -p ember-android-ffi
```

Android Kotlin unit and test vector suite:
- `android/app/src/test/java/com/ember/mobile/EmberCoreTest.kt` verifies core version, text drop roundtrip, file drop roundtrip, and shared drop test vectors (`testvectors/drop-v1.json`) including negative tampering cases.
