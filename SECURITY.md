# Security policy

Ember is a privacy tool, so security reports are welcome and taken seriously.

## Reporting a vulnerability

Email: **security contact pending** (to be set before the first public release; see
`docs/EMBER_BUILD_GUIDE.md` section 8, item 1). Until then, open a private security
advisory on the repository host.

Please include steps to reproduce, affected version, and impact. Do not include real
user data. We aim to acknowledge reports within 3 working days.

## Scope

In scope: the core library, protocol, relay server, Android app and web receiver.
Out of scope: attacks that require a compromised device, and copies kept by a
recipient (screenshots, camera). These limits are stated openly to users.

## Disclosure

Please give us reasonable time to fix an issue before publishing details. We will credit
reporters who want credit. A signed release and a reproducible-build guide are planned
(milestone M12).
